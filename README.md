# Кот-пожарный: мини-приложение Telegram

В этой папке готовый проект: игра, сервер и бот. Внутри Telegram у игры есть:

- **вход через Telegram.** Игрок ничего не вводит, сервер проверяет подпись Telegram (`initData`);
- **сохранение в аккаунте.** Прогресс, монеты, скины и настройки переносятся между телефоном и компьютером;
- **рейтинг на каждом из 6 уровней.** Топ-50 и место игрока;
- **монеты за Telegram Stars.** Четыре пакета, чек от Telegram, зачисление после подтверждения оплаты, возвраты;
- **вибрация и системные мелочи.** Отклик на тушение и удары током, кнопка «Назад», вопрос перед закрытием во время смены, отключён свайп, который случайно сворачивает игру.

Вне Telegram (по обычной ссылке) игра работает как раньше, все эти функции в ней просто спят.

```
tg-miniapp/
  server.js        сервер: игра + API + webhook бота (Node.js 18+, без зависимостей)
  public/game.html сама игра (тот же файл, что и в артефакте)
  terms.txt        условия покупки (бот показывает их по /terms)
  .env.example     пример настроек
  Dockerfile       для хостингов с Docker
```

## Что нужно

1. Аккаунт Telegram с включённой **двухэтапной проверкой**. Telegram требует её от владельцев ботов, которые продают за звёзды.
2. Хостинг, где Node.js-программа работает постоянно и доступна по **HTTPS**. Подойдут Railway, Render, Fly.io или свой VPS.
3. **Постоянный диск** для папки `data/`. В ней лежит база (`db.json`): профили, рейтинги, платежи. Если хостинг стирает диск при перезапуске, всё это пропадёт.

## Шаг 1. Создать бота

1. Открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Придумай имя и адрес бота. BotFather пришлёт **токен** вида `1234567890:AA...`. Его никому не показывай.
3. Желательно задать аватар (`/setuserpic`) и описание (`/setdescription`).
4. Узнай свой числовой id у [@userinfobot](https://t.me/userinfobot). Он понадобится для админ-команд.

## Шаг 2. Выложить сервер

Удобнее всего через GitHub: залей папку `tg-miniapp` в репозиторий, а потом подключи его к хостингу.

**Railway** (проще всего, диск есть):

1. New Project → Deploy from GitHub repo, выбери репозиторий.
2. Settings → Networking → Generate Domain. Получишь адрес вида `https://xxx.up.railway.app`.
3. Добавь Volume и смонтируй его в `/app/data`.
4. В Variables добавь переменные из шага 3.

**Render:** New → Web Service из репозитория. Start command: `node server.js`. Добавь Disk с путём `/opt/render/project/src/data`. На бесплатном тарифе диска нет и сервис засыпает, поэтому для настоящего запуска нужен платный.

**Свой VPS:** установи Node 20, скопируй папку, запусти `node server.js` через `pm2` или `systemd`. HTTPS проще всего получить через Caddy: `caddy reverse-proxy --from твой.домен --to :3000`.

## Шаг 3. Настройки

Скопируй `.env.example` в `.env` или впиши то же самое в переменные окружения хостинга:

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | токен от BotFather (обязательно) |
| `PUBLIC_URL` | HTTPS-адрес сервера без `/` в конце, например `https://xxx.up.railway.app` |
| `SUPPORT_CONTACT` | кому писать по оплате, например `@your_username` |
| `ADMIN_IDS` | твой числовой id; несколько через запятую |

После запуска сервер **сам** подключит webhook бота, поставит в чате кнопку меню «Играть» и добавит команды `/start`, `/paysupport`, `/terms`. В логах должна появиться строка «Бот настроен».

## Шаг 4. Проверить

1. Открой своего бота и нажми **«Играть»** (кнопка слева от поля ввода) или отправь `/start`.
2. Отработай смену и загляни во вкладку **«Рейтинг»**.
3. **«Снаряжение» → «Монеты за звёзды»**: отметь согласие с условиями и купи самый дешёвый пакет. После оплаты монеты придут в игру, а бот пришлёт сообщение.
4. Верни себе звёзды командой `/refund <id платежа>`. Id платежа покажет `/payments`.

Для тестов можно временно поставить пакету цену в 1 звезду: массив `PACKS` в начале `server.js`.

## Шаг 5 (по желанию). Красивая ссылка и кнопка в профиле

- В BotFather: `/newapp` → выбери бота → название, описание, картинка 640×360 → адрес `PUBLIC_URL` → короткое имя. Получится ссылка `https://t.me/имя_бота/короткое_имя`, ею удобно делиться.
- В настройках бота в BotFather найди раздел Mini App и включи там главное мини-приложение с тем же адресом. Тогда в профиле бота появится кнопка «Открыть».

## Как обновлять игру

Скачай новую версию игры из артефакта и замени файл `public/game.html`. Перезапускать сервер не нужно, он сам подхватит новый файл. Монеты, прогресс и рейтинг игроков сохранятся.

## Деньги и правила Telegram

- Цифровые товары в Telegram продаются только за Stars (валюта `XTR`). Платёжный провайдер не нужен.
- Монеты начисляются только после сообщения `successful_payment` от Telegram, повторные уведомления не начисляют их второй раз.
- Telegram требует от бота команды `/paysupport` и `/terms`, а также согласия с условиями перед покупкой. Всё это уже сделано. Текст условий меняй в `terms.txt`.
- При возврате (через `/refund` или самим Telegram) монеты списываются у игрока при следующем входе.
- Заработанные звёзды копятся на балансе бота. Вывести их можно через Fragment по правилам Telegram; подробности на странице про оплату звёздами (ссылка ниже).

## Ограничения

- База — один JSON-файл. Для нескольких тысяч игроков этого хватит. Если игра разрастётся, базу лучше перенести в SQLite или Postgres.
- Игра считается на телефоне игрока, поэтому упорный читер может подделать очки. Сервер отсекает явно невозможные результаты и частые отправки, но полной защиты в такой игре не бывает.
- Если играть на двух устройствах одновременно, останется прогресс того, которое сохранилось последним.
