# Кот-пожарный в Telegram: лёгкая версия без сервера

Это одна страница `index.html`. Сервер, база и оплата хостинга ей не нужны.

Что работает внутри Telegram:
- вся игра;
- прогресс, монеты, скины и настройки сохраняются в облаке Telegram, поэтому переносятся между телефоном и компьютером;
- вибрация, кнопка «Назад», вопрос «Закрыть?» во время смены, отключён свайп, который случайно сворачивает игру.

Покупок за звёзды и рейтинга здесь нет. Для них нужна полная версия с сервером.

## 5 шагов

**1. Аккаунт на GitHub.** Зарегистрируйся на [github.com](https://github.com), если аккаунта ещё нет.

**2. Репозиторий с игрой.**
1. Нажми «New repository». Назови его, например, `cat-firefighter`, выбери **Public** и нажми «Create repository».
2. На странице репозитория нажми «uploading an existing file», перетащи туда файл `index.html` и нажми «Commit changes».

**3. Включить GitHub Pages.**
1. Settings → Pages.
2. В Source выбери «Deploy from a branch», ветку `main`, папку `/ (root)`, нажми «Save».
3. Через 1–2 минуты вверху страницы появится адрес вида `https://твой-ник.github.io/cat-firefighter/`. Открой его в браузере и проверь, что игра запускается.

**4. Бот в Telegram.**
1. Открой [@BotFather](https://t.me/BotFather) и отправь `/newbot`.
2. Придумай имя и адрес бота (адрес должен заканчиваться на `bot`). Токен, который пришлёт BotFather, для лёгкой версии не нужен, но никому его не показывай.

**5. Привязать игру к боту.** Сделай оба пункта.
- **Кнопка в чате с ботом.** В BotFather: `/mybots` → твой бот → Bot Settings → Menu Button. Пришли адрес из шага 3 и название кнопки, например «Играть».
- **Ссылка, которой можно делиться.** В BotFather отправь `/newapp`, выбери бота и пришли:
  - название;
  - описание;
  - картинку 640×360 (подойдёт скриншот игры);
  - адрес из шага 3;
  - короткое имя, например `play`.

  Получится ссылка `https://t.me/имя_бота/play`.

Готово: открой бота и нажми «Играть».

## Как обновлять игру

Загрузи в репозиторий новый `index.html` поверх старого (Add file → Upload files → Commit). Через минуту обновление увидят все. Прогресс игроков сохранится.

Чтобы сделать `index.html` из новой версии игры из артефакта, попроси Claude. Можно и вручную: в начало файла игры вставь строки из начала этого `index.html` до `<body>` включительно, а в конец допиши `</body></html>`.

## Если что-то не так

- **Игра открывается, но прогресс не переносится между устройствами.** Обнови Telegram: облачное сохранение работает с версии 6.9 мини-приложений. Без него прогресс хранится только на этом устройстве.
- **В России Telegram и его сайт иногда блокируются.** Если у игрока не загрузится служебный скрипт Telegram, игра всё равно запустится, просто без вибрации и облака.
- **Изменения не видны.** GitHub Pages обновляется 1–2 минуты. Потом закрой и снова открой мини-приложение.
